# Update or Delete Topic

Managing topics allows users to update or delete existing topics in the Dima application. Users simply open the Topics page, select the desired topic, edit its information or delete it as needed, and confirm the changes.

This workflow is intended for users who want to keep their topics organized and up to date.

---

## Step 1: Open the Analytics page

![Placeholder screenshot for the Analytics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step1.png)

Tap the **Analytics** icon in the bottom navigation bar to open the Analytics page.

---

## Step 2: Open the Topics page

![Placeholder screenshot for the Topics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step1.png)

Tap the **Topics** icon in the top-right corner of the header to open the Topics page.

---

## Step 3: Open the topic options

![Placeholder screenshot for the three-dot topic menu](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step3.png)

Tap the three-dot menu next to the topic title to open the available options.

---

## Step 4: Choose an action

![Placeholder screenshot for the Update and Delete options](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step3.png)

Tap **Update** to edit the topic or **Delete** to remove it.

---

## Step 5: Update the topic details

![Placeholder screenshot for the topic edit form](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step4.png)

Edit the topic title and description as needed.

---

## Step 6: Save the updated topic

![Placeholder screenshot for the Update Topic button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/update-or-delete-topic/update-or-delete-topic_step5.png)

Tap the **Update Topic** button to apply the changes to the selected topic.

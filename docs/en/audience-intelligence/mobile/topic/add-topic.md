# Add Topic

Adding a topic allows users to create and monitor topics of interest within the Dima application. Users simply open the Add Topic page, enter the required information, and save the topic.

This workflow is intended for users who want to track specific topics and receive related data and notifications.

---

## Step 1: Open the Analytics page

![Placeholder screenshot for the Analytics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/add-topic/add-topic_step1.png)

Tap the **Analytics** icon in the bottom navigation bar to open the Analytics page.

---

## Step 2: Open the Topics page

![Placeholder screenshot for the Topics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/add-topic/add-topic_step2.png)

Tap the **Topics** icon in the top-right corner of the header to open the Topics page.

---

## Step 3: Open the Add Topic page

![Placeholder screenshot for the Add Topic button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/add-topic/add-topic_step3.png)

Tap the floating action button on the Topics page to open the Add Topic page.

---

## Step 4: Enter the topic details

![Placeholder screenshot for the topic details form](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/add-topic/add-topic_step3.png)

Enter the topic title and description in the required fields.

---

## Step 5: Create the topic

![Placeholder screenshot for the Add Topic submission button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/topic/add-topic/add-topic_step4.png)

Tap the **Add Topic** button to create the new topic using the information you entered.

# Own Page - Topic Insights

Explore the **Topic Insights** tab in **Own Page** to analyze topics, trends, and insights related to your page data. The **Groups** page follows the same general functionality and flow.

This workflow is intended for users who want to explore topic-based trends and insights related to their page activity.

---

## Step 1: Open the Analytics page

![Placeholder screenshot for the Analytics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-topic-insights/own-page-topic-insights_step1.png)

Tap the **Analytics** icon in the bottom navigation bar to open the Analytics page.

---

## Step 2: Open the Topic Insights tab

![Placeholder screenshot for the Topic Insights tab](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-topic-insights/own-page-topic-insights_step2.png)

Tap the **Topic Insights** tab to view topic-related analytics and insights.

---

## Step 3: Open the topic filter

![Placeholder screenshot for the topic filter](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-topic-insights/own-page-topic-insights_step3.png)

Tap the topic filter to select the topic you want to analyze and view its related data.

---

## Step 4: View the topic filter page

![Placeholder screenshot for the topic filter page](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-topic-insights/own-page-topic-insights_step4.png)

View the topic filter page to select and manage the topics you want to analyze.

---

## Step 5: Apply the filter

![Placeholder screenshot for the Apply button in the topic filter](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-topic-insights/own-page-topic-insights_step4.png)

Tap **Apply** to update the page with insights and data for the selected topic.

# Own Page - Monitor

Explore the **Monitor** tab in **Own Page** to track and analyze your page activities, mentions, and related data. The **Groups** page follows the same general functionality and flow.

This workflow is intended for users who want to monitor page activity, review posts, and analyze related engagement data.

---

## Step 1: Open the Analytics page

![Placeholder screenshot for the Analytics icon](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-monitor/own-page-monitor_step1.png)

Tap the **Analytics** icon in the bottom navigation bar to open the Analytics page.

---

## Step 2: Open the Monitor tab

![Placeholder screenshot for the Monitor tab in Own Page](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-monitor/own-page-monitor_step2.png)

Tap the **Monitor** tab in **Own Page** to access monitoring data and track page activities.

---

## Step 3: View the Monitor page

![Placeholder screenshot for the Own Page monitor view](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-monitor/own-page-monitor_step3.png)

View posts and monitor page activities from the **Monitor** tab.

---

## Step 4: Open AI Copilot

![Placeholder screenshot for the AI Copilot button in the monitor view](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-monitor/own-page-monitor_step4.png)

Tap the AI Copilot button to ask questions and get insights about the monitored posts.

---

## Step 5: Enter a question

![Placeholder screenshot for the Copilot input box in the monitor view](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/own-page/own-page-monitor/own-page-monitor_step5.png)

Write any question in AI Copilot to get insights and answers about the monitored posts.

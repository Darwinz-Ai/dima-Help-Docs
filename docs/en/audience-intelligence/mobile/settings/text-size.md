# Text Size

Changing the text size allows users to customize the application's text size for a more comfortable reading experience. Users simply open the Text Size settings, choose their preferred text size, and apply the changes.

This workflow is intended for users who want to improve readability based on their preferences.

---

## Step 1: Open the navigation menu

![Placeholder screenshot for the highlighted header button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step1.png)

Tap the highlighted button in the top-left corner of the header to open the navigation menu.

---

## Step 2: Open the Settings screen

![Placeholder screenshot for the Settings option in the menu](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step2.png)

Scroll to the bottom of the navigation menu and tap **Settings** to open the application settings.

---

## Step 3: Open the Text Size setting

![Placeholder screenshot for the Text Size option](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step3.png)

Tap the **Text Size** button to open the text size settings page.

---

## Step 4: Choose your preferred text size

![Placeholder screenshot for the text size slider](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step4.png)

Move the text size slider to choose between small, medium, and large text sizes.

---

## Step 5: Review the selected size

![Placeholder screenshot for the selected text size preview](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step5.png)

Adjust the text size again if needed until the preferred reading size is selected.

---

## Step 6: Save the new text size

![Placeholder screenshot for the Save button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/text-size/text-size_step6.png)

Tap the **Save** button to apply and save your selected text size.

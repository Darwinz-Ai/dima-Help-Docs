# Change the Application Language

Changing the application language allows users to switch between the available languages at any time. Users simply open the settings screen, select their preferred language option, and apply the change.

This workflow is intended for users who want to use the application in a different language.

---

## Step 1: Open the navigation menu

![Placeholder screenshot for the highlighted header button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/change-application-language/change-application-language_step1.png)

Tap the highlighted button in the top-left corner of the header to open the navigation menu.

---

## Step 2: Open the Settings screen

![Placeholder screenshot for the Settings option in the menu](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/change-application-language/change-application-language_step2.png)

Scroll to the bottom of the navigation menu and tap **Settings** to open the application settings.

---

## Step 3: Tap the language toggle

![Placeholder screenshot for the language option in Settings](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/change-application-language/change-application-language_step3.png)

The language option appears at the top of the **Settings** screen. Tap the toggle button next to it to switch the application language.

---

## Step 4: Confirm the language switch

![Placeholder screenshot for the language switched state](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/settings/change-application-language/change-application-language_step4.png)

Tap the language toggle button again if needed until the preferred language is selected. The application will then reflect the updated language choice.

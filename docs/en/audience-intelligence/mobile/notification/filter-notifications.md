# Filter Notifications

Filtering notifications allows users to quickly find specific notifications in the Dima application based on their preferred criteria. Users simply open the Notifications page, apply the desired filters, and view the filtered results.

This workflow is intended for users who want to organize and locate notifications more efficiently.

---

## Step 1: Open the filter panel

![Placeholder screenshot for the Filter button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step1.png)

Tap the **Filter** button to open the notification filter panel.

---

## Step 2: Select the filter options

![Placeholder screenshot for the filter options panel](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step2.png)

The available filter options will be displayed. Select the filters you want to apply to the notifications.

---

## Step 3: Filter notifications by type

![Placeholder screenshot for filtering by notification type](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step3.png)

Select one or more notification types to display only the notifications that match the selected type.

---

## Step 4: Filter notifications by date

![Placeholder screenshot for filtering by date or date range](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step4.png)

Select the desired date or date range to display notifications within the selected period.

---

## Step 5: Continue through the filter selection

![Placeholder screenshot for the highlighted filter action](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step5.png)

Tap the highlighted control to continue reviewing or refining the selected notification filters.

---

## Step 6: View the filtered results

![Placeholder screenshot for the filtered notifications list](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step5.png)

The notifications list will be updated to display only the notifications that match the selected filters.

---

## Step 7: Reset the filters

![Placeholder screenshot for the Reset All button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step6.png)

Tap the **Reset All** button to clear all selected filters and restore the default notification list.

---

## Step 8: Apply the filters

![Placeholder screenshot for the Apply button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/filter-notifications/filter-notifications_step8.png)

Tap the **Apply** button to apply the selected filters and update the notification list.

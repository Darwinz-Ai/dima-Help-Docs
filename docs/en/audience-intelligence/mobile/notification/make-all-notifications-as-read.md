# Make All Notifications As Read

Marking all notifications as read allows users to quickly mark every notification in the Dima application as read. Users simply open the Notifications page, select the Mark All as Read option, and confirm the action.

This workflow is intended for users who want to clear all unread notifications at once.

---

## Step 1: Open the Notifications page

![Placeholder screenshot for the View All button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/make-all-notifications-as-read/make-all-notifications-as-read_step1.png)

Tap the **View All** button to open the Notifications page and view all available notifications.

---

## Step 2: Tap the Read All button

![Placeholder screenshot for the Read All button](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/make-all-notifications-as-read/make-all-notifications-as-read_step1.png)

Tap the **Read All** button in the top-right corner of the header to mark all notifications as read.

---

## Step 3: Confirm the action

![Placeholder screenshot for the confirmation dialog](https://storage.googleapis.com/mediamonitor/dimabothelp/images/ar/audience-intelligence/mobile/notification/make-all-notifications-as-read/make-all-notifications-as-read_step3.png)

A confirmation dialog will appear asking whether you want to mark all notifications as read. Tap **Yes** to proceed or **No** to cancel the action.

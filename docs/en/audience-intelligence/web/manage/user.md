# Managing Users

<video controls=""><source src="https://storage.googleapis.com/mediamonitor/dimabothelp/images/en/audience-intelligence/web/manage/users/users.mp4" type="video/mp4"></video>

The **Users** screen is where you can manage who has access to your workspace (such as your "Made for You" dashboards) and control their permissions. By assigning specific roles, you ensure the right team members have the appropriate level of access, whether they just need to view data or actively edit content.

You can manage all workspace users directly from the [Manage](/en/manage/users) page.

---

## 1. Accessing the Users Menu

![Screenshot of the Manage module with the Users tab highlighted](https://storage.googleapis.com/mediamonitor/dimabothelp/images/en/audience-intelligence/web/manage/users/access-users.png)

All user management takes place in one central location:

1. Navigate to the main sidebar and click the **Manage** icon.
2. Select the **Users** tab located in the secondary menu.

---

## 2. Adding a User

![Screenshot showing the dialog that prompts the user to pick a User Role for the new team member](https://storage.googleapis.com/mediamonitor/dimabothelp/images/en/audience-intelligence/web/manage/users/select-user-role.png)

1. From the Users tab, click the **Add User** button in the top right corner of the page.
2. You will be prompted to select a **User Role** for the new team member. The role you choose dictates their permissions and the information you need to fill out:

**Viewer**
Viewers can only view shared dashboards and their content.

- **Username:** A unique identifier used for logging in.
- **Display Name:** The name visible within the workspace.
- **Contact Email:** The email address associated with the user.
- **Password & Confirm Password:** Create a secure login password.
- **Timezone:** Select the user's local time zone from the dropdown menu.

**Editor**
Editors can view and edit content, but only for the specific companies you assign to them.

- **Assigned Companies:** Choose the specific companies this user is allowed to edit.
- **Username:** A unique identifier used for logging in.
- **Display Name:** The name visible within the workspace.
- **Password & Confirm Password:** Create a secure login password.
- **Timezone:** Select the user's local time zone from the dropdown menu.

3. Click the **Add User** button at the bottom right corner of the form to create the profile and grant them access.

---

## 3. Editing a User

![Screenshot showing the three-dot menu on a User card with the Edit User and Delete User options](https://storage.googleapis.com/mediamonitor/dimabothelp/images/en/audience-intelligence/web/manage/users/users-crud.png)

If you need to update a user's details or adjust an editor's assigned companies:

1. Locate the specific user card you want to update in your list.
2. Click the **vertical three-dot menu ( ⋮ )** in the top right corner of that specific card.
3. Select **Edit User** from the dropdown menu.
4. Update the available fields depending on their assigned role.

> **Important Restrictions:**
>
> - You **cannot** edit or change a user's `Username` once their profile has been created.
> - You **cannot** change a user's role (e.g., switching a Viewer to an Editor). If a team member needs a different role, you must delete their current profile and create a new one.

5. Click **Update User** in the bottom right corner to save your changes.

---

## 4. Deleting a User

> **Warning:** Deleting a user will immediately revoke their access to your workspace. If they are a Viewer, they will lose all ability to see shared dashboards.

1. Locate the specific user card you want to remove.
2. Click the **three-dot menu ( ⋮ )** in the top right corner of the card.
3. Select **Delete User** from the dropdown menu.
4. A confirmation pop-up will appear to ensure you want to proceed. Click the **Delete** button at the bottom right to finalize the removal.

A user is a login credential that can be used to access dima platform. Users can be assigned a separate login and password other than the admin one to allow different permissions for each user. You can add users that only have access to specific companies on your account or have view only access to the account.

### [1\. Click the Manage icon, then open the Users tab](https://dimaapp.darwinz.ai/en/manage/own-page)

Click the Manage icon to open the Manage page, then click the **Users** tab. \[the Users tab sits on the right of the sidebar, under Topics and above Deleted Posts\]

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/86851d92-ceba-4c6d-8b71-76f70283572d/1/6.0416668653488/35.452057302815?0)


### [2\. Choose the company the user belongs to](https://dimaapp.darwinz.ai/en/manage/users/add/editor)

Pick the company you want to add the user in by clicking it in the companies list on the left (Red Bull, Concentrix Egypt, Ischool, and so on). At least one company is required, and you can select several to give the user access across multiple companies.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/ecb19080-239d-41a1-8c14-6a361ca54a0e/1/52.109377582868/53.26027386809?0)


### [3\. Click on Add User](https://dimaapp.darwinz.ai/en/manage/users)

\[the Add User button is at the top-right corner of the page, under the company's logo\]

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/4ac73e5b-4da0-4ab3-bc62-a470bfdc74f1/1/98.385414977868/9.972603157775?0)



### [4\. Select the user's role](https://dimaapp.darwinz.ai/en/manage/users)

Choose the role for the user by clicking the option you want in the role selector at the top of the form — this controls what the user is allowed to do inside the company.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/b53c6fc9-3e55-4976-aaf7-8b8418f2168a/1/59.283856550852/41.938355328286?0)

### [5\. Enter the requried feilds: Username, Display Name, Password, Confirm Password, Timezone](https://dimaapp.darwinz.ai/en/manage/users/add/editor)

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/40da8a31-1771-4715-8103-5ce7617bf378/1/63.281251986821/22.904109170992?0)



### [6\. Click on Add User](https://dimaapp.darwinz.ai/en/manage/users/add/editor)

\[located at the bottom-right corner of the page\] This saves the new user. Remember, you can add a single user in one or more companies at the same time.

![](https://d3q7ie80jbiqey.cloudfront.net/media/image/zoom/7f05ae53-0656-4f45-b0f9-7a7b5a965e32/1/97.552086909612/94.544518875749?0)
